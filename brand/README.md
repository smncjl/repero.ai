# Repero AI Brand Identity v1.0

This directory contains the production source for the Repero AI identity. The existing application icon in `public/brand/` is deliberately not duplicated, edited, or regenerated here; it remains the canonical app, favicon, avatar, and mobile mark.

## Contents

- `logo/` — the new typographic R glyph.
- `wordmark/` — official horizontal wordmarks.
- `social/` — ready-to-edit SVG social canvases.
- `templates/` — minimal reusable social starting points.
- `tokens/` — platform-neutral design tokens.
- `guidelines/` — usage rules and decision rationale.

All SVGs use explicit view boxes, semantic titles, no raster content, and Inter as their compatible text face. The custom R remains a vector path so its signature geometry is consistent everywhere.
